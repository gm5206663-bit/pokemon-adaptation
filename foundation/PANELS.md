# PANELS.md — panels are banned, and here is the reasoning

## The law

**k05 — no panels in prose. k06 — no panel lines in a chapter body.**

**There is also no panel in `STATUS.md` any more.** Snapshot v1 of that file
carried a nine-row meter table with percentages and counted inputs. It was
struck on 2026-09-30. Receipt:
`_archive/2026-09-30_system_framework_struck/RECEIPT.md`.

## Why the ban is total rather than partial

The obvious argument is stylistic: in a non-human POV the story is the beast's
(the Devouring Dragon law). That argument is true but it is not the whole thing.

**The real reason is that there is nothing to panel.** This OC holds Adaptation
Talent, not a System. There are no meters, no grades, no percentages. A panel
would not be an intrusion into the prose — it would be a **lie**, because it
would report numbers that the serial does not have.

The Bagon has no numbers. It does not know it is partway through anything. It
knows that the rock used to win and now it does not.

## What prose does instead

| Never write | Write |
|---|---|
| a percentage | the neck stopped aching before the stone did |
| a level | it hit the same rock all winter, and the rock lost |
| a technique changing name | the blow landed differently, and the OC noticed |
| a threshold being reached | something it could not do in autumn, it did in spring |
| a counter ticking | a season passing, shown by what the body can now carry |

**The test:** if a reader could put a number on it, the sentence is wrong.

## What `STATUS.md` holds instead

States, in sentences. Stage, condition, what it can do, what it cannot, hunger,
injury. When the body changes, the sentence changes — and it changes the same
turn as the chapter that caused it (k18).

**Drift rule, kept from the workspace:** if a chapter changes something true
about the OC and `STATUS.md` does not change in the same commit, the gate
catches it. A fact maintained in two places will be wrong in one of them, and the
check reads the other.

## What this file is still for

It is the receipt for a decision, not a spec for a feature. If a future agent
arrives and wonders whether a status panel could be added for clarity, this file
is the answer: no, and here is why, and it was the author's word.
