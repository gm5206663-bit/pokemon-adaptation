# CODEX.md — file map and decision log

## Authority order

author word > `RAILS.md` > `FOUNDATION.md` > `STATUS.md` > this codex >
`README.md` > everything else.

Where two files disagree, **the more specific file wins**, and the stale one is
fixed the same turn with a dated receipt. A fact maintained in two places will be
wrong in one of them, and the check reads the other.
